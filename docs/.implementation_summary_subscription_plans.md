## 🚀 How to Use

### Run Migrations & Seeder:
```bash
php artisan migrate:fresh --seed
```
This will:
1. Create fresh database tables
2. Seed all subscription plans
3. Assign subscriptions to existing shop users

### Access the Interface:
1. Login as **admin**
2. Go to sidebar → **Subscription Plans**
3. URL: `/admin/subscription-plans`

## 📋 What the Seeder Does

The `UserSubscriptionSeeder` will:
- Distribute shop users across different plans (Free Trial, Monthly Basic, Premium, Yearly plans)
- Set realistic start/end dates for each subscription
- Assign payment statuses (paid, free, expired)
- Create one expired subscription for testing

### Example Distribution:
- User 1 → Free Trial (active, 5 days remaining)
- User 2 → Monthly Basic (paid, 20 days remaining)
- User 3 → Premium (paid, 25 days remaining)  
- User 4 → Yearly Basic (paid, 10 months remaining)
- User 5 → Yearly Premium (paid, 11 months remaining)
